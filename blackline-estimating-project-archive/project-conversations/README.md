# Project conversation archive — staging

This folder is an **additive, read-only copy destination** for the Estimate Scoping Tool project's conversations.

## Status
- Project chat **metadata and selected excerpts** are available in the current conversation context.
- **Complete original transcripts have not been provided or imported.**
- The `conversation-index.md` is therefore a preliminary index, not a certified complete record.
- The original conversations remain inside ChatGPT; nothing here changes, moves or deletes them.
- The existing application and GitHub `main` branch are not modified.

## Import protocol
1. Obtain a user-authorised ChatGPT data export.
2. Identify conversations belonging to this Project using export metadata, not title guesses alone.
3. Preserve original text and timestamps, and hash each source file.
4. Review personal/client data, confidential quotations, credentials and third-party material before committing.
5. Keep original exports immutable; create separate searchable summaries and decision records.
6. Record coverage, source, revision and any missing attachments. Never promote a proposed chat idea to an approved standard without documented approval.
