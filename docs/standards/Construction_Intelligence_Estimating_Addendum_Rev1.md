# 3Bears Construction Intelligence — Estimating Operating Addendum Rev1

**Status:** Approved operating addendum for integration into the next controlled Master Prompt revision.  
**Date:** 8 September 2026

## Mandatory Construction Intelligence backend check

Before researching or inserting any external rate, productivity, methodology, supplier, standards, escalation, disposal, cartage, market, programme or other reusable construction-intelligence input into an estimate:

1. Read the current **3Bears Construction Intelligence Master Reference**.
2. Search the live **3Bears Construction Intelligence Register** first:
   https://docs.google.com/spreadsheets/d/1ummWFxW0EHctJOENT3nu4jHTnGp_UOoZ6FF5uSxqJKk/edit
3. Reuse a central record only when its geography, scope, specification, unit, tax basis, delivery/hire basis, inclusions/exclusions, validity and task/site conditions are aligned to the project.
4. Retain the record's GREEN / AMBER / RED evidence status and source references in the project estimate.
5. If the central evidence is missing, stale, contradictory or non-comparable, research externally rather than forcing the central record to fit.
6. Feed useful new verified evidence back to the central register under change control.
7. Never silently overwrite a live estimate or Master Estimate Workbook from the central register.
8. Never create a competing project-specific central intelligence database.

## Productivity rule

A productivity input must not be reused as a naked output number. Confirm, where material:

- crew composition
- plant
- paid and productive hours
- net task time versus gross elapsed production
- task size, depth, geometry and complexity
- access and staging
- material handling
- ground/site conditions
- weather exposure
- testing and hold points
- rework/quality assumptions
- work fronts and dependencies

If these conditions are not sufficiently comparable, the productivity remains AMBER or RED for project use even where the source itself is credible.

## Source hierarchy and verification

The current Estimating Triple Verification Standard continues to govern. GREEN requires:

1. primary/current evidence;
2. independent check; and
3. first-principles/scope check.

A GREEN source does not automatically create a GREEN project input.

## Integration rule

The Construction Intelligence Register is a backend evidence source only. The project cost chain remains:

**Resource Rate Library → Resource Build-Up → QS Takeoff → Tender Build-Up → Summary → Cashflow / Programme**

Risk Truth, Weather Risk and other approved specialist engines retain their existing integration pathways.
