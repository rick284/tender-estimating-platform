## Access
Use the authenticated GitHub connection for rick284/tender-estimating-platform (private). Read this folder and its instructions before estimating. GitHub access does not automatically attach these files to a ChatGPT Project; download/upload them if the Project needs permanent attachments.

Download the repository using Code > Download ZIP, or clone/pull it. Run `python mason-project-sources/restore_and_verify.py` from the repository root. The script reconstructs the largest PDF (file 35) from four numbered parts and verifies the SHA-256 and size of all 40 originals. All other originals are directly available in this folder.
